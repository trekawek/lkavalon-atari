# LK Avalon sources

Repository contains sources of LK Avalon games and programs for 8-bit Atari.

Most original sources were downloaded from [Atari XL/XE Source Archive](http://sources.pigwa.net/), transformed from ATASCII to ASCII with [convert-atascii.go](util/convert-atascii.go) and manually cleaned up. The assembly sources can be compiled with [MADS](https://mads.atari8.info/). The Forth games listed below were reconstructed from their released disk images and rebuild through the original APX fig-Forth compiler.

## Requirements

* MADS assembler
* GNU make
* golang - optionally, for running extra tools
* Python 3 - for Heartlight's cave data and Watson's packed source tools
* Python 3 with py65 - for the original fig-Forth compiler used by A.D. 2044, Klątwa, and Władcy Ciemności

## Compilation

The older game directories can be compiled with:

```bash
mads main.asm -o:game.xex
```

Directories can be built with make (see each Forth game's README for its setup):

```bash
make
```

Run the available build checks with:
```bash
make test
```

Heartlight builds a standalone XEX from its original objects and the caves embedded in its BASIC loader. Automat Perkusyjny builds the original disk and cassette XEX files byte for byte. Watson assembles two source revisions, but its archive has no matching executable for a binary comparison. See each directory's README for details.

The three reconstructed Forth games assemble native 6502 routines through
`src/06-assembler.fth`, a target assembler written in Forth and loaded by the
stock APX interpreter. Instructions use explicit addressing modes, such as
`LDA.# 03`, `STA.ZP D1`, and `JSR.ABS E456`; branches name their hexadecimal
destination address. Headers, tables, strings and unclassified mixed regions
remain byte data. This keeps the saved dictionary's original addresses while
making verified machine code editable as mnemonics. See each game's source
notes for the syntax and remaining reconstruction limits.

## Building the Forth games from assets

AD 2044, Klątwa and Władcy Ciemności build fresh game ATRs from the checked-in
Forth sources, structured data and native graphics/font/CMC files. No ATR,
SAP, program snapshot or sound-bank binary is stored for these three games.
`make` generates `reference/figforth.atr` from the readable APX dictionary,
6502 mnemonics and ASCII screens in [util/figforth](util/figforth). Its 58 boot
sectors reproduce the original compiler exactly. Unloaded stale editor data
on the historical compiler disk is omitted.

Original game images are optional forensic fixtures in ignored
`build/reference/`. Without fixtures, recovery and verification accept an
unchanged rebuilt game only after checking its historical SHA-256 from
`reference/sources.json`. No build step downloads or reads an original game disk.

| Game | Authoritative graphics | Authoritative music |
| --- | --- | --- |
| AD 2044 | `ad2044/graphics/packed/*.bin`, including fonts and cursor | `ad2044/music/sound-bank.json` |
| Klątwa | Native records selected by `klatwa/assets/layout.json`, `graphics/fonts/*.fnt`, `graphics/sprites/*.bin`, `graphics/cursors/player-planes.bin` | `klatwa/music/*.cmc` |
| Władcy Ciemności | Native records selected by `wladcy-ciemnosci/assets/layout.json`, `graphics/fonts/*.fnt`, `graphics/sprites/*.bin`, `graphics/cursors/player-planes.bin` | `wladcy-ciemnosci/music/*.cmc` |

Each game's `assets/layout.json` lists the disk resources, sizes and physical
spans. Editable JSON documents under `assets/` preserve object/action tables,
room definitions, interaction maps, messages, saved state and allocation residue.
Nested record lengths and string lengths are calculated by their encoders.
Interaction maps expose rows of object IDs, not packed pixel dumps; Klątwa and
Władcy retain compression token boundaries to reproduce their original streams.
Small unidentified fragments remain explicitly annotated values/fills. The shared
[packer](util/pack_assets.py) creates the ATR header and GAM directory, fills
unused space with zero, and writes the resources around sector 500. It rejects
missing files, incorrect sizes, malformed length prefixes and overlapping
writes. The program area starts blank and is generated by Forth.

Embedded cursor data and AD 2044's sound bank use `INCBIN path` in the source
listings. This is a build directive: [forth_assets.py](util/forth_assets.py)
encodes the JSON sound bank and expands the resulting bytes, or the native
cursor pixels, to ordinary ASCII `BYTES` lines before both host compilation
and source-screen packing. The sound JSON itself contains 6502 mnemonics,
voice settings, envelopes and named music commands. `build/sources.atr` therefore contains complete Forth
source that can be compiled with the original Atari `LOAD` command.

After editing an asset or structured resource, run the corresponding Makefile:

```sh
make -C ad2044
make -C klatwa
make -C wladcy-ciemnosci
```

`make assets` only packs the resource disks; `make sources` rebuilds the Forth
source ATR. To list the exact disk inputs, run
`python3 ../util/pack_assets.py --dependencies` from a game directory. Asset
sizes and CMC load addresses are fixed by the reconstructed game layout;
growing or relocating an asset requires corresponding layout/code changes.
Władcy's gameplay CMC has six restored runtime bytes: the packer validates
them and omits them from its shorter disk resource.

PNG previews, decompressed pictures and room compositions are derived graphics.
Whole-group dumps, decoded hit-map binaries and SAP playback wrappers are
generated only under ignored `build/graphics` and `build/music`. `make graphics`
re-extracts the original release for inspection; `make music` exports the current
music inputs. Neither overwrites source assets. `make test` checks against the
original release and therefore expects unmodified inputs.

[structured_assets.py](util/structured_assets.py) encodes one resource directly:

```sh
python3 util/structured_assets.py --game-dir ad2044 \
  music/sound-bank.json --output ad2044/build/music/sound-bank.bin
```

The per-game [AD2044](ad2044/assets/README.md), [Klątwa](klatwa/assets/README.md)
and [Władcy](wladcy-ciemnosci/assets/README.md) format notes explain editable
fields and unresolved residue. Each `assets/binary-migration.json` records the
replacement of former binary inputs or redundant exports. Run
`python3 util/audit_forth_binaries.py` to enforce the tracked-file policy.

All three Makefiles were tested in an isolated tree containing only declared
text sources and the allowed native graphics/font/CMC inputs, with no starting ATRs. All 4,160 rebuilt game sectors matched
the reference releases. The generated source ATRs also passed the original
Atari fig-Forth `LOAD` path, and mutation tests checked that native asset edits
reach both disk packing and Forth compilation.

## Extracted music

* [Klątwa music](klatwa/music): original title and gameplay CMC modules, six subsongs.
* [Władcy Ciemności music](wladcy-ciemnosci/music): title and gameplay CMC modules, three subsongs. The gameplay module restores six bytes used from adjacent runtime memory; see its [extraction notes](wladcy-ciemnosci/README.md#music).
* [A.D. 2044 music](ad2044/music): structured custom player, envelopes, title/ending music, game-over cue and effects. `make music` generates SAP listening files and the encoded bank under `ad2044/build/music`. This release uses a custom player rather than CMC.

Each music directory contains `extraction.json` with source offsets, original
load addresses, hashes and any restoration or player adaptations. Regenerate
all exports with Python 3, independently of the Forth build:

```sh
python3 util/extract_music.py
python3 util/extract_music.py --check
python3 util/test_extract_music.py
```

[ASAP](https://asap.sourceforge.net/) can play the CMC and SAP files. Optional
independent validation loads and renders every subsong into temporary WAV files:

```sh
python3 util/extract_music.py --check --asapconv /path/to/asapconv
```

All 31 exported subsongs (including 20 AD 2044 effects) were rendered with
ASAP 8.0.0. The original-player regression checks additionally use `py65`:

```sh
python3 ad2044/tools/test_music_sap.py
python3 util/test_cmc_playback.py
```

## Extracted graphics

Graphics are stored in custom GAM FORTH resource records, rather than ordinary
image files. The exports preserve their packed bytes and decoded bitmap data,
with PNG previews, fonts, and static room compositions:

* [A.D. 2044 gallery](ad2044/graphics/index.html) and [format notes](ad2044/README.md#graphics).
* [Klątwa gallery](klatwa/graphics/index.html) and [format notes](klatwa/README.md#graphics).
* [Władcy Ciemności gallery](wladcy-ciemnosci/graphics/index.html) and [format notes](wladcy-ciemnosci/README.md#graphics).

Open a gallery locally to browse the files. Each directory also has
`rooms-overview.png`, paginated contact sheets, and `extraction.json` with
resource IDs, physical disk offsets, dimensions, palette evidence and checksums.
PNG bitmap previews double the horizontal pixels to match the Atari display
aspect. Grayscale previews identify assets whose contextual colors are unknown;
the stored bitmap and original color-register bytes remain unchanged.

Regenerate or check the exports using Python 3, independently of Forth compilation:

```sh
python3 util/extract_graphics.py
python3 util/extract_graphics.py --check
python3 util/test_graphics_common.py
```

Each game also provides `make graphics` and `make test-graphics`. Install
`py65` to include comparisons with the original 6502 decompression routines;
the other extraction checks use only the standard library. The native files
listed above feed the game builds; PNGs and decoded compositions are previews.
