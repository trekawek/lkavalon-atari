# Interface pictures and credits

- `title.png`: title screen; its changing scanline colors remain in Forth code.
- `frame.png`: the interface surrounding the room picture.
- `title.fnt`, `game.fnt`: raw 992-byte Atari fonts, 124 eight-byte glyphs each.
- `cursor.pmg`: the three 13-byte player/missile graphics planes used by the cursor.
- `credits.txt`: all rotating title messages, in sections `[00]` through `[07]`.

See the shared [graphics format](../../FORTH.md#graphics) for PNG editing rules.
AD2044's full screens have 160 by 105 stored pixels, with only the first 104 rows
displayed. The title's color changes come from the executable.
Fonts are compiled into disk resources; the cursor is embedded in Forth code.

Each quoted string in `credits.txt` is one displayed line; spaces inside quotes
are significant. Keep the section IDs consecutive from zero. Counts, lengths
and enclosing records are generated by the builder.

Polish capitals use the known game-font slots. The title font uses ASCII spaces
and has a lowercase `z` in the slot that the gameplay font uses for `Ż` and `Ź`.
`\\xNN` inside a quoted string preserves an uncertain, inverse or special glyph
byte exactly. Gameplay messages remain alongside their actions; the ending text
is inline in [../ending/scene.txt](../ending/scene.txt).
