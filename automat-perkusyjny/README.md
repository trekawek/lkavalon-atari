# Automat Perkusyjny

![Automat perkusyjny](img/automat-perkusyjny.png)

This directory contains source of Automat Perkusyjny (software drum machine), developed by  Maciej Miąsik and published by LK Avalon in 1991.

## Source files

Original program:
