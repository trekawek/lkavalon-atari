Klatwa semantic-name recovery
============================

This pass identifies words from their released code, callers, state tables,
action labels and Atari hardware accesses. The descriptive aliases do not
claim to restore the author's erased spellings. Dictionary headers, target
addresses, machine instructions and resource bytes remain unchanged.

build/research/symbols.txt records per-word evidence, stack effects and decoded callers.
Edit tools/inferred-names.json for persistent manual naming evidence;
make research merges it with recovered names and regenerates the Forth,
build/research/dictionary.json, symbols.txt and string-catalog owner names. Callers in the
catalog cover decoded colon calls and COMPILE operands, not every native
reference, DOES> tail or data-driven action dispatch.

MEMORY MAP AND EXECUTABLE CHECKS

The Atari OS cursor uses a column cell at $55 and row byte at $54. STICK0
starts at $0278; the trigger word reads GTIA $D010, not the OS trigger shadow.
The joystick converter at $50A3 accepts a controller number and reads the
corresponding shadow byte. This differs from AD2044's converter, which accepts
an already-read joystick value. Trigger zero means pressed.

Action parameters are bytes in a selected record with a two-byte length.
$671D adds the parameter offset and two to the record pointer at $6694;
$672F reads the resulting byte. This is checked using a synthetic record
passed to the original routines, not a host reimplementation of their logic.

$69C0 counts set bits in all 31 room-marker bytes at $587E..$589C. $69E8
updates the byte selected by the current room at $556F only when none of the
requested mask bits is already present. It then adds the mask. In particular,
current byte 1 with requested mask 3 remains 1; this is not general bitwise OR.
$7200 maps four directions to their opposites: 0<->2 and 1<->3.

All 54 action slots were checked against their labels and handler PFA table.
Shared handlers keep a single name. The ten decorated records at $5577 are
spellbook entries, not inventory slots; the inventory is room 0/view 1 in the
mutable object table. Group 6 message resources 46/47 identify the warlock's
hourglass-for-jewel exchange, providing evidence beyond the handler's shape.

Native helpers $6E36 and $6F2F return with RTS. Their catalog entries carry
assembly calling conventions rather than ordinary Forth stack contracts.

The semantic tests run the original 6502 instructions and Forth dispatcher
from the release. Their bounded routines need no Atari OS stubs or simulated
interrupts. They check all nine joystick positions on four controllers,
trigger bits, cursor storage, signed range boundaries, byte search, action
fields, room-marker updates/counting, inventory operations, resource IDs,
banked span splitting, coordinate differences and direction opposites. These are
behavioral probes of selected words, not a full gameplay test.

AUTHOR TUTORIAL COMPARISONS

The eleven tutorials previously examined for AD2044 also help distinguish
shared language/runtime facilities from game-specific code in Klatwa.
Their educational examples are not the missing commercial source screens.
The preserved GAM sources provide additional comparison material.

Issues 1-4/92 describe variables, allocation and Boolean control flow. Reserved
buffers can contain stale editor data; those bytes do not by themselves prove
that a buffer is an active text resource. The introductory PAUSE example
resets the clock, while this game's $429B waits for successive changes of the
RTCLOK low byte $14.

Issue 5/92 and issue 11-12/92 corroborate X!, Y!, X@, Y@ and POS at
$39F0/$39FE/$3A0C/$3A1A/$3A29. The complete bodies and surviving header
characters provide stronger evidence than mere dictionary position.

Issue 6-7/92 supplies <=<. The complete threaded body at $38F4 and its
surviving header agree. Despite the suggestive spelling, the implementation
uses strict signed comparisons: lower < value < upper. Tests include both
bounds and negative values.

Issues 8-10/92 explain the postfix assembler, two-byte parameter stack cells,
X as the stack pointer, NEXT/POP/POPTWO and the distinction between native
Forth words and JSR/RTS subroutines. These conventions inform the native-code
analysis. The reconstruction's separate prefix assembler keeps operand width
explicit so recompilation preserves absolute addressing below $0100.

The INSTR example in issue 11-12/92 searches backward. Klatwa's search at
$3896 instead returns the one-based first match, like AD2044's version.
A repeated-character probe distinguishes the two behaviors. The tutorial's
name is therefore not treated as proof of an identical routine.

Issue 1-2/93 discusses memory beneath the OS ROM. Such examples establish
useful conventions, but similar parameter roles alone do not establish an
erased game word's original name.

UNRESOLVED AND BUILD VALIDATION

w3817/w3821: cell initially $81 and its accessor, without a proven role.
w3FCA: cell cleared during initialization, without a proven reader.
w4E64: small reserved allocation without an established consumer.
w569E: small indexed cell allocation without an established game role.
w5872: constant 30 without a proven consumer.

There are 896 named entries: 106 intact originals, 229 core/source matches,
28 structural candidates and 533 descriptive inferences. This pass added
502 inferred names and strengthened six existing candidates with source
matches. Structural candidates remain explicitly qualified.

All 18,067 dictionary emission tokens are unchanged after resolving target
aliases to their CFA. Assets also match the pre-renaming files. The 210-screen
source ATR was compiled by original APX fig-Forth in Atari800 from 32,000
initially blank program/residue bytes. The complete 133,136-byte ATR matches
the release. Host HERE=$89E5 leaves 5,403 bytes below $9F00. See the local
build/runtime-validation/semantic-load-report.json. Only evidence comments
were refined after that run; repacking produces the identical source ATR.
